# giel-sp-assignment3
Code required for GIEL Scientific Principles assigment 3.

## Build Instructions

To run this app you'll need [Python](https://www.python.org/downloads/) installed on your machine. I installed it on my Mac using Homebrew. Clone or download the code from GitHub to your machine and open the directory in an IDE like VScode. Create a new virtual environment using `python -m venv .venv` and activate it with `source .venv/bin/activate`. Install the required package dependencies in the requirements.txt using `pip install -r requirements.txt`, then run the app with `python chip_network_solver.py`.
